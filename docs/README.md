Quick pointers, for the two questions that come up most:

- **The solution changed and nothing looks wrong.** Check `cutOffElevation` and
  `noiseGPSCode` in `config/spp.ini` first — see [config.md](config.md).
- **A figure or report field is missing or misplaced.** The column layout is
  specified in [data-format.md](data-format.md), and the parser is
  `python/src/gnss_plot/io.py`.

The main [README](../README.md) covers what the project is, how to build it, and
the accuracy results.
